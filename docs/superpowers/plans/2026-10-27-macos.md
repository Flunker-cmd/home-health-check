# macOS: implementation plan (2 of 4)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `home-inventory` and `router-health-check` run on macOS and Linux, and add a `macos-health-check` skill, all under stock `/bin/bash` 3.2 without sudo, installs or permission dialogs.

**Architecture:**
- Three new standalone bash scripts:
  - `home-inventory/scripts/discover.sh`, with the same output as `discover.ps1`
  - `router-health-check/scripts/probe.sh`, with the same sections as `probe.ps1`
  - `macos-health-check/scripts/collect.sh`
- Each script is self-contained, because Agensi delivers every script on its own. Small helpers (`with_timeout`, `norm_mac`, `parse_arp`) are copied into each script that needs them, not sourced.
- Every script keeps its logic in functions, and its last line is exactly `main "$@"`. A repo-only test harness, `tools/test-sh.sh`, sources each script without that line and runs its pure parsing functions against anonymized fixtures captured from the author's Mac and Pi.
- `tools/check-skills.ps1` gets rules for bash 3.2 syntax, macOS portability and macOS permission safety.

**Tech Stack:** bash 3.2 (macOS) and bash 5 (Debian, Git Bash), BSD and GNU userland, perl (stock on macOS and Debian, used only for the SSDP multicast), curl, Windows PowerShell 5.1 (checker), Markdown SKILL.md.

**Spec:** `docs/superpowers/specs/2026-10-27-modular-home-health-check-design.md`. Plan 1 (`docs/superpowers/plans/2026-10-27-core-and-agensi-packaging.md`) is done. Its contract, checker and packaging are what this plan builds on.

Work on a new branch `macos` off local `main`. Plan 1 is not pushed yet. Do not push.

## Global Constraints

- Everything from plan 1's Global Constraints still applies: English skills, read-only collectors, the privacy placeholders (MACs ending in `00:00:00`, IPs in `192.168.1.x`, IPv6 in `2001:db8::`), scripts under 20480 bytes, and build output outside the repo.
- **bash 3.2:** no associative arrays, `mapfile`/`readarray`, `${var,,}`/`${var^^}`, `|&`, `&>>`, `coproc`, `declare -n`, `[[ -v`, `;;&`, `wait -n`, `printf '%(...)T'`.
  - The new scripts use **no arrays at all**. In bash < 4.4, `"${arr[@]}"` on an empty array fails under `set -u`. Use newline-separated strings and temp files instead.
  - `read -t` takes whole seconds only.
- **Portable userland** in `discover.sh`, `probe.sh` and `macos-health-check/scripts/collect.sh`:
  - No `timeout` (macOS has none; use `with_timeout`), no `grep -P`, `sed -i`, `date -d`, `stat -c` or `readlink -f`.
  - `awk` must be POSIX awk: no `gensub`, `strftime` or `asort`.
  - Branch on `uname -s` (`Darwin` or `Linux`) where tools differ:
    - `ping` timeout flags: macOS `-t <s>`, Linux `-W <s>`
    - `arp -an` versus `ip neigh`
    - `nc` connect timeout: macOS `-G 1`, Linux `-w 1`
- **Stdin-safe:** every script works when run as `bash script.sh ...`, as `bash -s -- ... < script.sh`, and over `ssh host 'bash -s -- ...' < script.sh`. No script uses `$0`, `dirname "$0"` or `BASH_SOURCE` to find files.
- **No sudo** in the three new scripts.
- **No macOS permission dialogs (TCC).** The new scripts never:
  - run `osascript`, `mdfind`, `tccutil` or `sqlite3`
  - touch `~/Desktop`, `~/Documents`, `~/Downloads`, `~/Pictures`, `~/Movies`, `~/Music`, `~/Library/Mobile Documents`, `~/Library/Mail`, `~/Library/Messages`, `~/Library/Safari`, `~/Library/Containers` or `/Volumes/`

  If a fact needs Full Disk Access or admin rights, the script prints `not checked: <area>: <reason>` and moves on. `<reason>` is one of `needs Full Disk Access`, `needs admin`, `timed out` or `not available`.
- **Local Network privacy (macOS 15+):** Apple TN3179 says command-line tools run from Terminal or over SSH, and their children, are exempt. A tool started by an app (an IDE or a desktop agent app) is attributed to that app, and macOS asks once whether that app may access the local network. This is an OS dialog that the scripts cannot avoid when the LAN is their job. So:
  - `discover.sh` and `probe.sh` print a hint when it looks like access was denied.
  - Both SKILL.md files disclose the dialog in *Network and permissions*.
  - The macOS collector makes no LAN connections, so it never triggers this dialog.
- **Script options:** `--long` flags. `discover.sh` and `probe.sh` also accept the PowerShell spellings (`-Ports`, `-Oui`, `-Json`, `-Sweep`, case-insensitive). `--help` prints usage and exits 0. An unknown option prints usage to stderr and exits 2.
- **Data directory in shell:** `${HOME_HEALTH_CHECK_DIR:-$HOME/.home-health-check}`. An empty value counts as unset. No other environment variable is read.
- **Temp files:** one `mktemp -d` directory per run, removed by `trap ... EXIT`. Nothing else is written, except `<data dir>/cache/manuf.txt` by `discover.sh --oui`.
- **Version:** `plugin.json` and every SKILL.md go to `0.4.0`.
- **Fixtures:** anonymized captures from real devices live in `tools/fixtures/`. Raw captures stay in a temp folder outside the repo (the author's global instructions say where) and are never committed.

## Review Focus

1. **The agent runs inside an app on macOS 15+** (an IDE, or a desktop agent app), not in Terminal. Expected: SKILL.md warns before the first scan that macOS may ask once for Local Network access. If access was denied and no neighbor answers, the script prints a hint instead of an empty table that looks like an empty network. Covered in Task 2, Step 1 (`lan_hint` test), and Task 6, Steps 2–3 (real runs).
2. **macOS `arp -an` prints MACs without leading zeros** (`b8:27:eb:0:0:0`). Expected: every MAC is normalized to `b8:27:eb:00:00:00` before it is printed, compared or written, so inventory matching by MAC works across Windows, macOS and Linux scans. Covered in Task 2, Step 1 (`norm_mac`, `parse_arp`).
3. **A script is delivered without a folder** (Agensi) or piped over SSH. Expected: `bash -s -- --help < script.sh` prints usage, and `bash -s -- --bogus < script.sh` exits 2, for all three scripts. Covered in Tasks 2, 3 and 4, Step 1.
4. **The serial number, hardware UUID or provisioning UDID** appears in `system_profiler` output. Expected: these never reach the collector output, the chat or the findings file. Covered in Task 4, Step 1 (`filter_hardware`).
5. **A command hangs on a Mac with no `timeout`:** `softwareupdate -l` when offline, `dns-sd` (which never exits), `codesign` on a huge app, or a slow `brew`. Expected: `with_timeout` kills it, the script prints `not checked: <area>: timed out` where relevant, and `$(with_timeout ...)` returns as soon as the command does rather than after the full timeout. Covered in Task 2, Step 1, and Task 4, Step 1.

### Task 2: `home-inventory/scripts/discover.sh`

**Files:**

**Interfaces:**

- Usage: `bash discover.sh [--ports] [--oui] [--json]`, with the same meaning as `discover.ps1`'s `-Ports`, `-Oui` and `-Json`.
- Text output:
  - The header line is the same as `discover.ps1`'s: `scanned: <YYYY-MM-DD HH:MM>  subnet: <net>/<prefix>  gateway: <gw>  devices: <n>`.
  - Then the hint lines, if any.
  - Then the table.
- JSON output: one object, `{"scanned","subnet","gateway","devices":[{"ip","mac","vendor","random_mac","name","upnp","ports"}]}`, with the same keys and types as `discover.ps1 -Json`. `random_mac` is a JSON boolean.
- Functions. Tested ones are marked *T*.
  - `with_timeout <secs> <cmd...>` *T*: runs the command, kills it after `<secs>`, and returns its exit status, or non-zero if it was killed.
  - `norm_mac <mac>` *T*: prints a lowercase 2-digit colon form. Accepts `:` or `-` separators, any case and 1-digit groups. Prints nothing for an incomplete or invalid MAC.
  - `is_random_mac <mac>` *T*: exit 0 if the second hex digit is `2`, `6`, `a` or `e`.
  - `mask_to_prefix <0xffffff00 | 255.255.255.0>` *T*: prints the prefix length.
  - `ip_to_num <a.b.c.d>` and `num_to_ip <n>` *T*
  - `parse_arp [<iface>]` *T*:
    - Input: `arp -an` output on stdin, in the macOS or the Linux net-tools format.
    - Output: `ip<TAB>mac` lines with normalized MACs.
    - Skips incomplete entries, `ff:ff:ff:ff:ff:ff`, `00:00:00:00:00:00`, `01:00:5e:*` and `33:33:*`, and entries on other interfaces when `<iface>` is given.
  - `parse_ip_neigh` *T*: the same output, from `ip -4 neigh` on stdin. Keeps only `REACHABLE`, `STALE`, `DELAY`, `PROBE` and `PERMANENT` entries.
  - `parse_dnssd_ptr` *T*: reads `dns-sd -Q ... PTR` output on stdin and prints the first added PTR target, without the trailing dot.
  - `parse_upnp_desc` *T*: reads a device description XML on stdin and prints `friendlyName | manufacturer | modelName | modelNumber`. Empty fields are left out. Only the first `<device>` is used.
  - `location_host_ok <ip> <url>` *T*: exit 0 only if the URL's host is exactly `<ip>`. The script fetches only LOCATION URLs that pass this, so a device can't point it at another host.
  - `oui_lookup <manuf file>` *T*: reads normalized MACs on stdin and prints `mac<TAB>vendor` for each MAC whose 24-bit prefix is in the file. It uses the same line format and regex as `discover.ps1`.
  - `ensure_oui` *T*: resolves `<data dir>`, creates `<data dir>/cache`, and moves a top-level `<data dir>/manuf.txt` there if the cache file is missing. It downloads with `curl -fsS --max-time 60` only if the file is missing or older than 90 days (`find ... -mtime +90`), downloading to a temp file and renaming it on success. It prints the cache path.
  - `json_str <s>` *T*: prints a JSON string literal. It escapes `\` and `"`, and removes control characters.
  - `print_json <scanned> <subnet> <gateway> <records file>` *T*
  - `print_table <records file>` *T*
  - `lan_hint <neighbor count> <os>` *T*: prints the Local Network hint line when the count is 0 and `<os>` is `Darwin`, and a generic "no devices answered" line when the count is 0 on Linux. Otherwise it prints nothing.
  - `main "$@"`
- The records file is internal: one TSV line per device, `ip mac vendor random(yes|no) name upnp ports`. Tabs and newlines in values are replaced by spaces when written.

- [ ] **Step 3: Write `discover.sh`**

  `with_timeout` must not block a surrounding `$( )`. Its watchdog gets its own output redirected:

  ```bash
  with_timeout() {
    secs=$1; shift
    "$@" & cmd=$!
    ( sleep "$secs"; kill "$cmd" 2>/dev/null ) >/dev/null 2>&1 &
    dog=$!
    wait "$cmd"; rc=$?
    kill "$dog" 2>/dev/null; wait "$dog" 2>/dev/null
    return $rc
  }
  ```

  Collection steps in `main`. The ps1 equivalent is in brackets.
  1. **Interface, IP, prefix and gateway:**
     - macOS: `route -n get default` and `ifconfig <iface>`, with the netmask through `mask_to_prefix`.
     - Linux: `ip route show default` and `ip -4 -o addr show dev <iface>`.
     - The prefix is capped at /22, so at most 1024 addresses are swept.
  2. **Ping sweep:** background pings in batches of 64, each followed by `wait`, with a 1 s timeout per ping.
